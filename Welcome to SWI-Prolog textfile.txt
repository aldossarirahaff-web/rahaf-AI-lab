2- house = abc.

3- edge(a,b) = edge(C,b).
Result: C = a.
Explanation: The terms can be unified because they have the same functor edge and the same number of arguments. C can be unified with a.

4- edge(a,d) = edge(C,B).
Result: C = a, B = d.
Explanation: The terms can be unified because C can become a and B can become d, making both terms identical.

5- edge(C,B) = edge(a,d).
Result: C = a, B = d.
Explanation: The terms can be unified because the variables C and B can take the values a and d.


6- edge(A,f(g,h)) = edge(a,B).
Result: A = a, B = f(g, h).
Explanation: The terms can be unified because A can become a and B can become f(g,h), making the two structures identical.

7- edge(A,A) = edge(b,c).
Result: false.
Explanation: The terms cannot be unified because the same variable A appears twice, so it must have the same value in both positions. It cannot be both b and c.

8- edge(A,A) = edge(b,b).
Result: A = b.
Explanation: The terms can be unified because both occurrences of A can have the same value, b.

9- A = B, B = f.
Result: A = B, B = f.
Explanation: The terms can be unified because A and B become linked, and B is unified with f. Therefore, both represent f.

10- A = B, B = f, A = e.
Result: false.
Explanation: The terms cannot be unified because A and B are linked. B = f makes A = f, but the last condition requires A = e. f and e are different atoms.
